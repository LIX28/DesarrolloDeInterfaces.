FASE 1

Ideación y Generación del Prompt Maestro

Herramienta: Gemini
Explicación del proceso (Contexto)

Primero se planifica la arquitectura de la web y cómo debe funcionar. Siguiendo la metodología de prácticas anteriores, se solicita ayuda a Gemini para redactar un prompt completo y estructurado que posteriormente se entregará a Claude. El requisito fundamental es gestionar todos los Puntos de Interés (POI) mediante un archivo data.json escalable, donde cada POI pueda tener de 0 a N imágenes ubicadas directamente en una carpeta raíz imagen/ (sin subcarpetas) para simplificar las rutas del fetch() en GitHub Pages.

Prompt inicial a Gemini + Prompt Maestro generado

// 1. Petición inicial enviada a Gemini:

"Hola, puedes, usando este documento, crear un prompt que pasarle a claude para crear una página web? La página va a ser desplegada en github pages. Quiero que controle un .json para añadir dentro de este los diferentes Puntos de Interes (POI) dentro suya. Este .json debe ser facilmente escalable. Y que la cantidad de Imagenes pueda ir desde 0 a la que se quiera. El .json hará referencia a imagenes dentro de una carpeta llamada imagen. No introduciré las imagenes dentro de otras subcarpetas dentro para facilitar el fetch de los datos del .json."

// 2. Prompt Maestro generado por Gemini para Claude:

Rol: Actúa como un desarrollador web experto en frontend (HTML5, CSS3 y JavaScript moderno) y experto en despliegues en GitHub Pages. Diseña y desarrolla el código completo para una página web de viajes interactiva basada en la República Dominicana, estructurada en múltiples vistas y totalmente responsive.

  • Gestión de Datos: Archivo data.json externo consumido con fetch(), escalable, con 0 a N imágenes en carpeta raíz imagen/ (ej. "imagen/punto1.jpg") sin subcarpetas.
  • Gama Cromática obligatoria: --color-1: #C8102E (Rojo), --color-2: #1F4E9C (Azul), --color-3: #F5F3EE (Beige claro), --color-4: #EEB7C0 (Rosa raro), --color-5: #2B2B2B (Oscuro) y #8FA6CE (Azul claro). Modo claro/oscuro suave.
  • Navegación: Menú horizontal en PC (oculto en Inicio hasta hacer scroll tras la cabecera, con logo centrado y opciones repartidas a los lados) y menú hamburguesa lateral en móvil.
  • Vistas: 1) Inicio (introducción con bandera en el texto "Conoce República Dominicana", preview de 4 POI y texto dinámico "conoce su..." que rota cada 30s); 2) Conoce RD (tarjetas con etiquetas, Maps, galería, enlace oficial y recorte a 3 líneas con "Ver más"); 3) Planifica tu viaje (buscador, filtros y ruta interactiva con waypoints y hover); 4) Contrata tu vuelo.
  • Easter Egg: Código Konami (↑ ↑ ↓ ↓ ← → ← → B A) en Inicio que intercambia los colores principales rojo y azul.
FASE 2

Resolución de Conflictos de Rutas y Anidación

Depuración de Estructura
Explicación del problema surgido

Al generar los primeros archivos del proyecto, surgió un problema de inconsistencia en la anidación de carpetas: index.html buscaba la hoja de estilos en ./css/styles.css, mientras que conoce.html y planifica.html buscaban styles.css directamente en la raíz, y todos apuntaban a app.js en la raíz en lugar de js/app.js. Esto provocaba que algunas vistas cargaran sin estilos. Se realizó una consulta de diagnóstico para unificar todo bajo una estructura limpia de carpetas.

Consulta sobre rutas y estructura unificada

"Estos archivos manejan la direccion styles.css y app.js o /css/styles.css y js/app.js?"

// Diagnóstico y estructura unificada resultante:

/ (Raíz del repositorio)
├── index.html       ──► apunta a css/styles.css y js/app.js
├── conoce.html      ──► apunta a css/styles.css y js/app.js
├── planifica.html   ──► apunta a css/styles.css y js/app.js
├── data.json
├── imagen/          ──► imágenes directas sin subcarpetas
├── css/
│   └── styles.css   ──► archivo único unificado
└── js/
    └── app.js       ──► lógica centralizada

FASE 5

Migración de Google Maps a Leaflet + OpenStreetMap

Regreso a Gemini
Explicación del cambio técnico

Al agotarse el límite de uso gratuito en Claude, se retoma el desarrollo con Gemini. En la página Planifica tu viaje surgió un bloqueo: la integración original utilizaba la API de Google Maps, la cual exige registro previo y tarjeta de facturación para obtener una API Key funcional. Para mantener el proyecto 100% gratuito, abierto y sin dependencias de claves privadas en GitHub Pages, se decide migrar el motor de mapas a Leaflet + OpenStreetMap.

Prompt enviado a Gemini

"puedes rehacer el .js para que en vez de usar una API de google maps use un Leaflet+OpenStreetMap?"

Antes: Google Maps JS API (requiere API Key y cuenta de facturación).
Después: Leaflet.js + OpenStreetMap (código abierto, sin registro y compatible con GitHub Pages).

Sistema de Favoritos, Spinner y Menú Hamburguesa

Herramienta: Gemini
Explicación de la mejora de UX y correcciones

Inspirándose en la web de Aron para evitar saturar el mapa con demasiados POI simultáneos, se implementa la función de guardar favoritos y mostrarlos en el buscador desplegable lateral derecho de Planifica tu viaje (junto con el cálculo de duración del trayecto entre puntos). Además, se unifican los colores de los botones en modo claro y oscuro, se estiliza el botón de tema (blanco con luna/sol), se ocultan las tags visibles en las tarjetas, se añade un spinner (desplegable) para filtrar favoritos por etiqueta, se vincula el fondo de las tarjetas al modo activo (azul claro en modo azul / rosa en modo rojo) y se repara el menú hamburguesa móvil.

"quiero que añadas la capacidad de añadir favoritos, y que los dichos se muestren en el buscador de "planiifca tu ruta" en dicha página ademas quiero que se vea una imagen, con los puntos del mapa marcados, indicando cuanto tiempo dura el trayecto. Quiero que TODOS los botones que contienenen el rosa y el azul claro en el modo oscuro, sean del mismo color en el modo claro. Quiero que el boton para cambiar de modo claro a oscuro sea de color blanco ademas de ser una luna en el oscuro y un sol en el claro. Las tags que aparecen en la página "conoce republica dominicana" y "planifica tu viaje" quiero que desaparezcan. En el modo planifica tu viaje, quiero que puedas filtrar tus favoritos haciendo usando las etiquetas que existen pero, por medio de un spinner. En cuanto a que la página sea multidispositivos, haz que el buscador sea un desplegable a la derecha de la página. Permitiendo ver el mapa, en la página "planifica tu viaje". quiero que las tarjetas en el "modo azul" (i.e. cuando el menu está azul) sean de azul claro el fondo, en vez de blanco. y viceversa (cuando este el menu rojo, el fondo de las tarjetas sea rosa). Y estos colores cambiaran al hacer click al logo como te indiqué antes. El menú de la hamburguesa no es funcional. Quiero que arregles eso."
